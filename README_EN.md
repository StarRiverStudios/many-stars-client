### IV-3: Client Installation Guide (Using Prism Launcher as an Example)
1. First, download the client modpack file from [Github Release](https://github.com/StarRiverStudios/many-stars-client/releases/latest).
2. Open the launcher and click `Add Instance`.
3. In the new instance window, select the `Import` option from the left sidebar.
4. In the import window, click the `Browse` button at the bottom and select the modpack file you downloaded.
5. Then click `OK` to start importing.
6. Wait for the import to complete (mods, resources, shaders, etc. will be downloaded automatically).
7. Launch the game.
